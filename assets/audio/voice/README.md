# 《回家吃饭》语音占位

**这四段不是真人录音**，是本机 TTS 生成的占位，用来把语音通道跑通：

| 文件 | 内容 | 处理 |
| :--- | :--- | :--- |
| `mom_msg.mp3` | 「今天回来吃饭不？我炖了汤。」 | 电话滤镜（300–3400Hz + 压缩） |
| `mom_door.mp3` | 「回来啦。」 | 干声，轻压缩 |
| `mom_dinner.mp3` | 「吃饭了。」 | 干声，轻压缩 |
| `boss_call.mp3` | 「那个方案，客户又改了口径。你今晚能不能，再出一版？」 | 电话滤镜 |

生成脚本：`tools/gen_voice.sh`（macOS `say` + `ffmpeg`）。

## 换真人录音

保持文件名不变，直接覆盖 `assets/audio/voice/*.mp3`，代码（`src/home/homeVoice.js`）不用改。

建议：

- 妈妈：50–60 岁女声，普通话带一点县城口音，语速偏慢；电话段可以更轻、更近麦。
- 老板：40 岁左右男声，语速快，电话段带一点不耐烦。
- 采样：mono 44.1kHz，mp3 64kbps 左右；单段 1–6 秒。
- 电话段做 300–3400Hz 带限；面对面段保持干声，不要加混响。
- 文件名、语义不要变；长度尽量接近原占位，太长会压过文字节奏。

## 为什么先只做四段

整部剧本约 350–420 条台词，全量真人配音是 30–50 分钟音频、两位以上演员、一次完整的录音/剪辑/对轴，和现在这个「一个人写的像素游戏」不是一个量级。

先用四段把「声音」这条路验证掉：妈妈的语音、门口一句、上桌一句、老板电话。这四段是情绪锚点，也是电话/面对面两种声场的样本。听感确认后，再决定要不要扩到全量。
