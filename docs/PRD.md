## 1. 定位与目标体验

一句话：**一个关于「借来的游戏机」的夏天**。玩家扮演 2004 年放暑假的小学生，客厅电视柜上那台小旋风不是自己家的，开学前必须原样还回去；48 天里能不能攒出一台自己的，是这个夏天唯一的正经目标。

三条设计基线，代码里到处都是它们的痕迹：

**一、玩法的心脏是「修卡」，不是「玩卡」。** 每张卡带带两个数值（`dirt` 脏、`wear` 磨损），主机卡槽另有一份灰（`slotDirt`）。开机失败会抽一种故障，故障现象直接把该做的事说出来：雪花就插到底、花屏就哈气、滚屏就在桌沿划、抖动就拍电视侧面、彩虹纹就吹卡槽。修法刻意做成「过犹不及」：哈久了湿气糊住触点反而更差，划多了在磨掉这张卡的命，而 `wear` **永久不可逆**，磨到 100 卡就彻底废了。这一层让「插上去能出画面」本身成为一件值得高兴的事。

**二、紧张感来自门外，不来自屏幕里。** 只要电视开着，`SB.Parent` 就在后台数秒，依次给三级信号（自行车铃 / 楼道脚步 + 心跳 / 钥匙插锁）。门开那一刻它只硬查两件事：电视关了没、卡带拔了没。所以玩家学到的不是背时间表，而是「听见铃声就该收摊」。

**三、钱是一毛一毛的，目标是看得见的。** 每天五毛零花钱，卖废品、退酒瓶、卖旧课本、帮人搬货各有零头，全部记进账本；集市上那台二手主机标价 45 元、每天在 41–49 之间浮动，心愿单和集市提示条常驻显示「还差多少」。48 天不是倒计时压力，是一条可以每天推一点的进度条。

不做的事同样重要：**心情不是资源条**（`SB.Story.mood`，不消耗、不阻塞任何操作，只影响结局变体和一个形容词）；章节不阻塞推进（不完成任何目标，48 天照样走完，结局照样出）。

## 2. 双层叙事：2026 的深夜，2004 的暑假

游戏有两层时间，代码里两个日期常量各写一次，别的地方一律引用：

| 层 | 时间 | 地点 | 出处 |
| :--- | :--- | :--- | :--- |
| 现实层（序章） | 2026 年 7 月 3 日 23:47 | 公司 18 层 → 电梯 → 楼下雨中等车 → 出租车后座 | `SB.STORY.PRO_SLUG / PRO_CLOCK / PRO_PLACE`（`src/data/story.js`） |
| 记忆 / 梦境层（游戏主体） | 2004 年 7 月 15 日起，暑假 48 天 | 客厅 / 集市 / 发小家 | `SB.STORY.DREAM_SLUG`，以及 `src/systems/timeSystem.js` 的 `START = new Date(2004, 6, 15)` |

叙事路径：2026 年那个深夜加班干完活 → 打车回家 → 后座刷到一个「二十年前的游戏机」的视频和评论区 → 眨眼三次没再睁开 → 蝉声、铁窗味道 → 有人在楼下喊你的小名 → 2004 年 7 月 15 日的客厅。**整个游戏主体是那一觉里的梦**；结局停在 2004 年 8 月 31 日，末尾两句「后来」把镜头轻轻拉回现在（`SB.L.story.endTail`），但没有一个「醒来回到 2026」的正式段落。

两层的写法刻意相反，这是文案约定，不是口味问题（`src/data/storyLines.js` 顶部有注释）：2004 靠物件堆质感（「暖水瓶。铁皮上的红花掉了漆，木塞子塞不严了」），2026 靠数字和进度（「发布完成 耗时 6 小时 12 分」「预计等待 14 分钟 前面还有 3 人」）。2004 不缺时间，2026 不缺东西、缺的是「这件事结束了」的感觉。

> **年份的两处坑**：① 小游戏开机标题卡上写的 `1994 XUANFENG`（`src/scenes/PlayScene.js`）和 StubGame 里的 `1994 UNKNOWN` 是**机器年份 / 致敬信息**，跟叙事年份无关，不要顺手改成 2004；② 仓库根的 `README.md` 开头仍写「1990 年代」，那是过时表述，本轮按约定未改动它。

### 3.2 节奏规则（当前实现）

早先是旁白自动往下走、A 只是加速，实测 12 镜像放幻灯片一晃就过。现在的规则：

| 情形 | 行为 |
| :--- | :--- |
| 一行打字中按 A / START / 点画面 | 立刻把这一行补完 |
| 一行打完 | 停住等输入，右下角闪 `▼`（620ms yoyo 呼吸） |
| 停住时按 A / START / 点画面 | 下一行；本镜最后一行则进下一镜 |
| 按 B 或点右上角「跳过」 | 结束序章（不可跳镜除外） |
| 跳过之后 | 补三行摘要 `SB.L.story.prologue.skip`，玩家至少知道自己为什么在 2004 年 |

序章**不自动翻页**：一切靠 `waitTap` 标记推进，`SB.STORY.prologue` 里每镜的 `holdMs` 是自动播放时代的遗留字段，`PrologueScene` 已经完全不读它。

### 3.3 门禁、存档位与重看

- 门禁在标题画面：`TitleScene` 里 `needPro = !s.flags.prologue && !s.__nostory`，需要就去 `Prologue`，否则直接 `Room`。
- 走完置 `flags.prologue = true`；如果是跳着看的，另置 `flags.prologueSkipped = true`。
- 交棒：`scene.start('Room', { from:'title', intro })` —— `SB.L.intro` 那七句开场照旧在客厅播，序章不抢客厅的戏。
- 重看：回忆册第一页常驻一条「那个晚上」（`SB.L.story.prologue.album`），按 A 或再点一次进 `Prologue`，`from:'album'` 时**不写存档**，看完回册子。

## 4. 一天怎么过：核心循环

```
起床（slot=0，AP=4）
  └─ 客厅 RoomScene：13 个可点物件
       ├─ 鞋盒 → 选卡 → 插卡（seated 62%）
       ├─ 主机 / 电视 → 开机 → 失败就抽故障 → 修卡台对症修 → 出画面
       ├─ 坐下来玩 → PlayScene（妈妈的秒表同时开始走）
       ├─ 小方桌 → 写作业（1 AP）
       ├─ 门 → 集市（1 AP）/ 发小家（1 AP）/ 睡觉
       └─ SELECT / 右上角「菜单」→ 心愿单 · 回忆册 · 设置 · 回标题
睡觉 → day++ / ap=4 / 发五毛零花钱 / 剧情按天结算 / 抽一个日常事件
```

时间尺度（`src/core/const.js`、`src/systems/timeSystem.js`）：

| 项 | 值 |
| :--- | :--- |
| 一天时段数 | 5（上午 09:00 / 中午 12:30 / 下午 15:00 / 傍晚 17:30 / 晚上 20:00） |
| 每天行动精力 AP | 4；`spend(n)` 后 AP 落到整数就推进一个时段 |
| 花 AP 的事 | 去集市、去发小家、写作业各 1 AP |
| 不花 AP 的事 | 修卡、开机、玩游戏；但一局玩超 **45 秒**离开时推进一个时段（在发小家不推） |
| 开局位置 | 第 1 天，`slot=2`（下午，妈还没回来），兜里 ￥3.5 |
| 暑假长度 | 48 天（7/15–8/31），第 48 天睡下走结局 |

### 5.3 心情与结局

心情 0–100，初值 60，全场只以一个词露面：

| 阈值 | 词 | 分档 tint |
| :--- | :--- | :--- |
| ≥85 | 美得很 | good |
| ≥68 | 挺得劲 | good |
| ≥45 | 不咸不淡 | calm |
| ≥25 | 有点闷 | warn |
| ≥0 | 一点劲都没有 | bad |

心情加减（`SB.STORY.moodDelta`）：被抓（电视开着）-14、被抓（只是卡带没拔）-8、蒙过去 +3（真写了作业时按 +5 传值）、通关 +12（同一张卡重复通关按 +4）、买到卡 +6、卡废 -10、连着 3 天只写作业不玩 -8、跟妈妈和解 +22、买到自己那台 +25。

| :--- | :--- | :--- |

| `own_cold` | 买到了 | 四十五块 |
| `lost_warm` | （信任 ≥65 或已和解）且 心情 ≥50 | 空了一块 |

| `default` | 其余 | 你还记得怎么哈那两口气 |

## 6. 核心系统与关键数值

细节公式见 [`prd_src/01_core_systems.md`](prd_src/01_core_systems.md)，这里只留「为什么是这个数」。

### 6.1 修卡（`src/systems/repair.js`）

```
risk = dirt*0.85 + slotDirt*0.35 + wear*0.75
      - 14（有 AV 线） + 12（天热且没风扇） + 18（假卡）
failChance = clamp(risk/160, 0.02, 0.95)
```

- 上下限 0.02 / 0.95：干净卡也允许偶尔翻车（那正是当年的样子），最脏的卡也留 5% 侥幸。
- 故障权重跟成因绑定（`GLITCH` 吃 `dirt`、`RAINBOW` 吃 `slotDirt`、`SHAKE` 吃 `wear` 且没 AV 线 +9），玩家能从现象倒推手法，不用背表。
- 哈气：`power<0.3` 无效、`>0.92` 反而 `dirt+7`，最佳区间 0.55–0.85；同一次修卡里第 n 口效果乘 `max(0.35, 1-(n-1)*0.22)`——湿气会积累。
- 划桌：前 3 下每下 `dirt-9` 不磨损；第 4–5 下 `dirt-4 / wear+2`；第 6 下起 `dirt-1 / wear+7`，`wear≥72` 出警告、`≥100` 卡带 `dead`。
- 每次开机本身 `dirt+0.6`、`slotDirt+0.4`：插拔就是消耗，长期看逼着玩家买棉签、买 AV 线。
- 棉签一次 `dirt-48` 且无副作用，但消耗一支（￥3）——花钱能买确定性，而钱是要攒主机的。

### 6.2 妈妈（`src/systems/parent.js`）

| 项 | 值 |
| :--- | :--- |
| 状态机 | `idle → armed → w1 → w2 → w3 → arrive` |
| 计时 | 妈在厨房 26–52 秒；妈出门 52–116 秒 |
| 警觉修正 | `paranoia = 1 - min(0.3, caught*0.06)`，被抓越多回来越快（最多快 30%） |
| 三级信号 | 55%（自行车铃 / 鱼缸气泡）、82%（楼道脚步 + 心跳循环音）、95.5%（钥匙插锁） |
| 门开检查 | 电视开着 → level 2（`why:'tv'`）；电视关了但卡带还插着 → level 1（`why:'cart'`）；否则安全 |
| 安全奖励 | `escaped++`，信任 +8（真写了作业，`homework≥60`）/ +4（只把本子摊开）/ +2（啥也没干） |
| 被抓代价 | `caught++`，信任 -16（level 2）/ -8（level 1），心情 -14 / -8 |
| 惩罚梯度 | `n = caught -（写了作业 ? 1 : 0)`：`n≤1` 或 level 1 → 罚写大字（`homework=100`）；`n==2` → 没收手柄到明天；`n≥3` → 没收卡带（`owned=false`） |

设计要点两条：**被抓的原因必须当场说明白**（`SB.L.story.busted.tv / .cart`），否则玩家永远学不会漏了哪一步；**上弦时给一句线索**（抽油烟机还在响 = 她还在厨房 / 她拿布袋子下楼了 = 楼下铃响就是回来了），把「随机出现」变成「有迹可循」。

### 6.2.1 抢救那三下（`src/systems/rescue.js`）

躲妈妈从「按一下 START 就没事了」改成一段要动手的操作。规则层是纯逻辑的 `SB.Rescue`，界面与输入在 `PlayScene`（`startRescue` / `judgeRescue` / `finishRescue`）。

| 项 | 值 |
| :--- | :--- |
| 三步 | `tv` 关电视 → `cart` 拔卡带 → `hide` 塞沙发缝，每步一根左右扫的判定条 |
| 进入 | 一、二级预警时按 START 手动进；三级预警（钥匙插锁）自动进 |
| 判键 | 抢救期间 A / B / START 都是「判一下」 |
| 三档 | `perfect` 不罚时间；`ok` 过关但给妈妈的秒表推 ~450ms；`miss` 这一步重来并推 ~1100ms |
| 压力 | `press()` 由妈妈剩余时间算：剩得越少压力越大，**判定区更宽但光标更快** |
| 期间 | 小游戏停更、妈妈秒表照跑、暂停菜单与右上角「离开」都封掉 |
| 结算 | `grade()` = `clean`（三步收完）/ `close`（收了一半她开门）/ `bare`（一下没收着），分别计 `stats.rescueClean / rescueClose / rescueFail`，客厅按等级给一句回收文案 |

这一段的设计意图：原来的「一键逃命」把最该慌的三秒变成了一次无风险点击。现在手里有三件事、时间只够做完，玩家才会真的手忙——而且**慌出来的每一次失误都换成妈妈往前多走一步**，惩罚是时间而不是弹一句失败提示。

### 6.3 经济（`src/systems/economy.js`）

| 项 | 规则 |
| :--- | :--- |
| 卡带标价 | 基准价 × (1 ± 17%)（按 `day` 与卡带 id 的整数散列，同一天进出集市不变）× (1 + (rarity-2)×4%)，下限 ￥2 |
| 杂货 | 一口价写死；只有标 `vary` 的二手主机按 `(day*97+41)%100` 做 ±9% 浮动 |
| 今日摊货 | 按 `(day*31+id*17)%10` 与稀有度门槛筛（rarity≥4 需 ≥7，==3 需 ≥5，其余 ≥2），不足 2 张则补到 2 张 |
| 砍价 | 底价 = 标价 ×(72% + (rarity-1)×3.5% + rnd(0,6%))，耐心 3；出价 ≥底价成交；≥底价 93% 摊主反报中间价、耐心 -1；更低耐心 -2；耐心归零今日谈崩 |
| 假卡 | 成交时按 `fakeChance` 判定，中了 `dirt+20`，当场不揭穿 |
| 成交后 | `dirt = startDirt + rnd(-8,12)`、`wear = rnd(0, startDirt/8)`、`stats.buys++`；砍下来的差价记进 `ledger.saved` |

## 8. 交互与输入

三路输入（键盘 / 实体手柄 / 屏幕虚拟手柄）在 `src/core/input.js` 合并成一副 8 键红白机手柄，`SB.Input.p1 / p2`。

| 动作 | 键盘（默认） | 实体手柄 | 触屏 |
| :--- | :--- | :--- | :--- |
| 方向 | ↑↓←→ | 十字键 / 左摇杆（阈值 0.45） | 左下十字键（画 104×104，**命中 136×136**，八向） |
| A | `X` `K` `Space` `A` | pad A 或 B | 右下 A 圆键（命中半径 27） |
| B | `Z` `J` `B` | pad X 或 Y | 右下偏左 B 圆键 |
| START | `Enter` `NumpadEnter` | buttons[9] | 右上长条 START |
| SELECT | 左右 Shift | buttons[8] | 右上长条 SEL |
| 2P 动作 | `H`=A、`G`=B | 第二只手柄 | 无（虚拟手柄只有 1P 一副） |

两层临时覆盖，是这套输入里最容易忘的部分：

- **同屏双打**（`setTwoP(true)`，发小家的坦克 / 格斗）：`WASD` 归 2P 方向，键盘 `A` 变成 2P 的左，1P 的 A 请按 `X`。
- **单人小游戏移动优先**（`setMove1P(true)`，`PlayScene` 开局打开、暂停时关掉、退场必关）：`WASD` 归 1P 方向，键盘 `A` 变成 1P 的左。理由写在代码注释里：真有人一坐下就按 WASD 想开坦克，结果坦克原地放炮，玩家只会得出「这游戏坏了」的结论；游戏里「移动」比「A=确认」要紧，确认还剩 X/Z/J/K/空格。菜单、客厅、修卡台这些屏幕上写着「确认 A」的地方，这一层一律关闭。

配套两件事：所有「按什么键」的提示都现算 `SB.Input.keyName() / tip()`，键盘玩家看真实键名、摸屏幕的看 A/B，且上面两层生效时 1P 的 A 自动写成 `X`；每张卡真正能动的那一刻，`src/core/keyguide.js` 在画面中央盖一张按键卡（3.5 秒自动淡出，任意键收掉），之后角上留一条很淡的常驻键位条，暂停菜单里可随时再叫出来。

鼠标 / 触屏可直接点场景物件；修卡台上还能长按卡带哈气、在卡带上左右划当作在桌沿蹭金手指（每 14px 换向算一下）；设置里打开麦克风后，`blowPower` 由 `SB.Mic.read()` 实时驱动，拿不到权限自动退回长按。

标题屏上还藏了一条秘技：**↑↑↓↓←→←→** 八下输对，弹出一页制作名单（`TitleScene.pollCode / openStaff / closeStaff`），按任意键收回。故意没用完整的 ↑↑↓↓←→←→BA —— 标题菜单会把 A 当确认吃掉，最后那两下会直接把玩家送进游戏。名单打开时主菜单必须一起关掉（`menu.close()`），否则底下的菜单会偷键；收回时原位重建。

## 9. 存档与兼容

- localStorage 键：`nianhong_save_v1`（改名前是 `subor_summer_save_v1`，第一次读档时自动搬过来，老键不删）；版本走 `v` 字段，当前 `VER = 3`。**新键定下来之后一个字符都不能再改。**
- `load()` 判定放宽到「只要是个带 `v` 的档就收」：老档要能读进来再迁移，比当前版本更新的档也不清，`merge()` 保证结构完整、多出来的键原样留着。
- `merge()` 以 `def()` 为基准递归回填，所以**数值和对象型状态一律不许塞进 `flags`**（`flags` 默认 `{}`，老档读出来是 `undefined`）；剧情状态集中在有显式默认值的 `story` 对象里。

| 迁移 | 做什么 | 为什么 |
| :--- | :--- | :--- |
| `from < 2` | 补「这台是借的」（`lent/dueDay`）、`told=false` + `legacyNote=true`、按 `owned.console2` 追认 `ownConsole`、把手上的钱记成账本 `total` 并标 `legacy`、心情按 `caught / momTrust` 估初值 | 老档的夏天已经过了一半，不能用一整段开场拦他，也不能让心愿单显示「一共进账 ￥0.0」 |
| `from < 3` | 一律 `flags.prologue = true` | 半路给老档插四分钟 2026 年的加班夜等于打断进度；想看的从回忆册第一条重看 |

新档默认值里几个需要记住的：`slot=2`、`money=3.5`、初始拥有 `02` 铁甲坦克与 `05` 100 万合 1、`slotDirt=22`、`pads=1`、`momTrust=50`、`story.mood=60`、`story.lent=true`、`story.dueDay=48`、`settings={crt:1, scanline:true, bgm:0.5, sfx:0.8, mic:false, shake:true}`。
