### 躲妈妈从「按一个键」改成「抢救那三下」 · 存档版本 3

`dd228bf`

在这之前，听见妈妈回来只需要按一下 `START`：电视自己关，人自己走。那一下太便宜了 —— 童年的记忆不是按一个键，是听见钥匙响之后手上全是活、脑子里只有一句「来不及」。

现在预警一响按 `START` 开始收拾，三件事按顺序来：**关电视 → 拔卡带 → 塞沙发缝**。每件事一根判定条，一个光标来回扫，看着条子按 `A`：

| 判定 | 后果 |
| :--- | :--- |
| 正好（偏差 ≤ `half × 0.34`） | 不罚 |
| 勉强（偏差 ≤ `half`） | 妈妈的秒表 `+450ms`，这步过 |
| 手滑了 | 妈妈的秒表 `+1100ms`，**这步重来** |

几条刻意的设计：

- **罚时直接推 `SB.Parent.t`**，不是扣自己的计时器 —— 手滑是真的把门推近了一点。抢救期间小游戏停着，妈妈的秒表照跑。
- **越急判定区越宽，但光标越快**（`half = 0.085 + 0.080p`，`speed = 0.80 + 1.30p`）。被逼到墙角时难度要降、紧张感要升，不是让人绝望。
- 第三级预警（钥匙插锁）**自动**进入收拾，不用再按。
- 暂停菜单不给开、右上角「离开」隐藏 —— 那两条都是绕过动作段的后门（菜单里本来就有「关电视，回客厅」）。
- 判定目标不钉在正中间，钉住了玩家就在背节拍，而不是看着按。
- 收场看世界的真实状态而不是自己记的账：本来就关着的电视自动算过，`clean` 要求一次没滑**且**卡真的塞进了沙发缝。干净收场 `momTrust +3`、心情 `+3`、解锁回忆「三下」。

规则全在新文件 `src/systems/rescue.js`（`SB.Rescue`，一个 Phaser 对象都不碰），画面在 `PlayScene` 的 `buildRescueLayer` / `drawRescue` / `judgeRescue`。存档 `stats` 加了 `rescueClean` / `rescueClose` / `rescueFail` 三个计数（`merge()` 兜底，老档自动补 0，VER 不变）。

**怎么验**：`node tools/gametest/rescue_test.js`（37 条）+ `node tools/gametest/flow2_test.js`（31 条，抢救那一段按新机制重写了）。

### 修好「按方向坦克只转头不走」—— 帧率越高越走不动

`dd228bf`

`TankGame.moveTank` 逐像素推进，靠 `t.acc` 攒够 1 像素才走一步。玩家坦克 `speed = 58 px/s`，60fps 下每帧攒 `0.97` —— 永远差一点点；而攒不够时它和「撞墙」一样返回 `0`，外层 `if (moved === 0) t.acc = 0;` 每帧把攒的清干净。结果是**机器越流畅，坦克越走不动**（慢机器上 `dt` 一大反而正常，所以这个 bug 会在 CI 上自愈）。

修法：攒不够返回 `-1`（别清 `acc`），撞墙才返回 `0`。敌人 AI 那条路径共用同一个返回值判断，一起修好了。

**怎么验**：`node tools/gametest/move_input_test.js`，45 过 / 0 挂（修之前 37 过 / 8 挂）。复盘写在 [`TESTING.md` §6.5](TESTING.md)。

## 附：两个反复咬人的坑

写在这里是因为它们不属于任何一次改动，但每个接手的人都会踩一次。完整版见 [`TESTING.md`](TESTING.md)。

1. **多数测试脚本的端口写死在源码里。** `8100` 是主力，坦克 `8102`、马里蘑 `8103`、拳霸 `8104`，命令行传参不生效。只有 `prologue_test` / `prologue_shots` / `bugfix_title_room_test` / `move_input_test` / `repair_anim_test`（默认 `8110`）能接端口或完整 URL。端口撞上别人的服务，你会得到一整片莫名其妙的失败。
2. **`repair_anim_test.js` 不能和别的套件并行跑。** 它的哈气力度按真实按住时长折算，机器一忙、帧一慢，760ms 的「合适力度」就会算成哈过头，脏污反而上升，出现「跳过之后照样结算：脏污 70 → 77」这种假失败。单独跑就是 30 过 / 0 败（脏污 70 → 59）。
