# 游戏层代码实现事实汇总

本文档汇总了《那年的红白机》中 Phaser 3.60 游戏层的核心架构、接口契约及具体卡带小游戏的实现逻辑。所有小游戏都跑在电视画面区的 `360 × 270` 坐标系里。

## 1. 游戏基类与接口契约 (GameBase.js)

所有卡带小游戏必须继承自 `SB.GameBase` 并挂载于 `SB.Games` 命名空间下（`cartridges.js` 里的 `game` 字段就是这个命名空间的键；找不到对应实现时宿主退化到 stub）。

### 实现清单
若要实现一张新卡带，开发者需完成以下工作：
- **构造函数**：调用 `SB.GameBase.call(this, host, opts)`。
- **生命周期方法**：
    - `create()`：初始化场景、加载资源、构建动画。
    - `update(dt)`：每帧逻辑更新，`dt` 为毫秒。
    - `destroy()`：清理引用与自定义数组（世界层与 UI 层由基类自动销毁）。
- **核心组件使用**：
    - 使用 `this.world` 容器放置随镜头滚动的实体。
    - 使用 `this.ui` 容器放置固定位置的 HUD。
    - 使用 `this.pad` / `this.pad2` 获取 1P/2P 输入状态。
- **暴露字段**：
    - `score` / `hiscore`：当前分与最高分（宿主用它写卡带的 `best`）。
    - `lives`：剩余命数。
    - `stage`：当前关卡号（某些特殊演出如崩溃卡会检测此字段）。
    - `over` / `cleared`：胜负标志位（`cleared` 会让宿主记 `stats.cleared` 并加心情）。
- **绘图助手**：优先使用 `spr/img/rect/txt/tile` 等基类助手，它们会自动处理图层挂载与缺图色块兜底。
- **杂志开关**：`this.hasMag()` 读 `SB.Save.d.owned.mag`——买了《电子游戏时代》才显示（部分卡带才生效）秘技。

## 2. 核心小游戏深度解析

### ContraGame.js (魂斗萝)
- **玩法**：横版跑轰，8 方向瞄准。
- **架构**：无物理引擎，基于 16×16 Tile 数组手算重力与平台检测，支持「下+A」穿透单向平台；有水塘（掉进去就死）。
- **AI 要点**：跑兵（自动小跑+间歇跳跃）、炮台（朝玩家点射）、自爆兵（冲刺并炸毁地面 Tile）。
- **道具**：N（初始）、M（大威力）、S（散弹）、F（火球）。
- **胜负**：每人 3 条命，全员出局则 GameOver；击毁关底要塞墙（三个弱点：核心、左右喷口）则通关。
- **2P 支持**：完整支持 2P 双打。
- **代码规模**：约 1192 行。
- **秘技**：输入 `上上下下左右左右BA` 得 30 条命并复活出局的玩家。**秘技码本身不需要买杂志**，买了杂志只是会在左下角把这行码写出来。

### TankGame.js (铁甲坦克1990)
- **玩法**：基地保卫战。
- **场景结构**：13×13 逻辑格（16px），地形内部按 8px「半格」存储（26×26 子格，战场 208×208），砖墙才能一半一半地崩；每个子格一个显示对象，用 `setCrop` 从 16px 图块里裁四分之一。
- **关卡**：4 张手写字符画地图（工厂等），每关敌人配比固定为 20 台（如第 1 关 14 普通 / 4 快速 / 2 装甲，越往后硬货越多），其中 3 台是带道具的红坦克。
- **敌人 AI**：普通/快速/装甲三种，具备随机转向与朝老鹰或玩家的寻路倾向；同屏最多 4 台。
- **道具 (6种)**：星星（升级）、头盔（无敌）、手雷（全屏炸）、铁锹（基地变钢墙）、坦克（加命）、计时器（定身）。
- **胜负**：老鹰被毁或 1P/2P 全死则败；清光本关敌人过关，打完第 4 关算通关。
- **2P 支持**：完整支持。具备三套不同配色（Skin 0/1/2）。
- **代码规模**：约 1484 行。
- **秘技（需买《电子游戏时代》）**：`SEL+B` 直接过关，`SEL+A` 满级送护盾；买了杂志还会开局多一条命（4 条）。

### MarioGame.js (超级马里蘑)
- **玩法**：经典平台跳跃，重点是跳跃手感（可变跳跃高度、走/跑、刹车、惯性、coyote 90ms、跳跃缓冲 110ms）。
- **关卡结构**：包含 1-1（晴天）、1-2（地下）及管道金币房。支持场景压栈切换；`stage` 在进入第二关时 +1。
- **AI 要点**：栗子怪（平移）、乌龟（踩后变壳，可踢飞造成连撞，约 4.5 秒开始抖、6 秒醒）、跳跳怪（定时弹跳）。
- **道具与状态**：
    - 问号砖/藏金币砖：顶出金币、蘑菇（变大）、火花（发射火球）、星星（无敌）。
    - 可破坏砖块：大状态可顶碎，并产生飞散碎片特效。
- **胜负**：触碰旗杆过关。
- **代码规模**：约 1686 行。
- **彩蛋与作弊**：
    - `CrashGame` 专用逻辑：盗版「未完成版」卡带就是盯着 `this.stage` 死机的。
    - 秘技（**需买杂志**）：`↓↓↑↑BA` 开启无限跳，`SELECT` 连按三下跳关；角落提示两条轮流显示。

### FightGame.js (拳霸98加强变态版)
- **玩法**：1V1 格斗，3 回合 2 胜，每回合 60 秒。
- **机制**：纯帧数据驱动（起手/判定/收招），具备 Hitstop（命中停顿）与连段修正；A=拳、B=脚，方向 + 键区分轻重/下段/跳攻/必杀。
- **2P**：同屏双打优先；单人时 2P 由 AI 接管——AI 走的是虚拟手柄输入，支持搓招（如 236A 气功波），具备难度自适应。
- **变态特性**：随机触发「半条血」暴击、「无限连」模式、电脑瞬间回血，并伴随乱码演出。
- **代码规模**：约 1565 行。
- **秘技（需买杂志）**：左下角挂一块必杀指令表（气功波 ↓→+A / 升龙拳 →↓→+A / 旋风腿 ↓←+B / 超必杀 ↓→+AB）——当年杂志最大的价值。

## 3. 演出型卡带实现 (StubGame.js)
- **MultiGame (合卡菜单)**：模拟「100 万合 1」目录（`SB.MULTI_MENU` 10 项），仅前三项 `ok:true` 可进，进去都是铁甲坦克的三套换皮（skin 0/1/2）；其余条目选择后黑屏并报错。
- **GarbleGame (乱码汉化)**：模拟汉化版开屏，标题乱码后进入内层游戏（优先 `contra`，退而 `tank`），游戏里所有非 ASCII 字符替换为「■」。
- **StubGame (空卡/死标题)**：仅展示循环背景与 BGM，标题不动，按键只提示「按 START 退出」。缺实现的 `game` 键（含 `null`）都落到它。
- **CrashGame (崩溃卡)**：底层包裹马里蘑（缺失则坦克），运行超 **40 秒**或内层 `stage > 1` 时强制触发「花屏死机」演出。

## 6. 双打与借卡（谁能两人一起打）
- 真支持同屏双打的只有 `tank` 与 `fight`；马里蘑是轮流上场，合卡目录只有 1P 能动（`src/core/keyguide.js` 的 `same` 字段就是这个信息）。
- **双人同屏只在发小家开得起来**：只有 `FriendScene` 会给 `PlayScene` 传 `twoP`。客厅的 `enterGame()` 一律单人；买了 `pad2` 也不会改 `Save.d.pads`（它始终是 1），所以客厅那张 2P 手柄贴图实际上不会出现。「在家两人同屏」代码未实现，仅在计划中。
- 发小家只有 4 张卡：`01` 魂斗萝、`04` 拳霸、`08` 足球小子、`11` 影子传书；在他家玩不占妈妈的秒表（`atFriend` 时不跑 `SB.Parent.update`），也不推进时段。
- 键盘 2P 是 `WASD` + `H`(A) / `G`(B)，此时 1P 的 A 请按 `X`；虚拟手柄只有 1P 一副，2P 只能用键盘或第二只实体手柄。
