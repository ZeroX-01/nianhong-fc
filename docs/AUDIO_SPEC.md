# 音频资源规范（AUDIO SPEC）

## 目标
《那年的红白机》全部音频。风格 = **红白机 8-bit 芯片音乐（2A03 音源模拟）** + 少量真实生活环境音的芯片化模仿。
禁止使用任何外部下载素材，全部用 Python 程序化合成。

## 技术要求
- 合成：Python + numpy 手写波形。可用波形：**方波（可变占空比 12.5%/25%/50%）、三角波、锯齿波、白噪声（含 1-bit LFSR 噪声）、周期噪声**。
- 采样率 44100Hz，单声道合成后可做轻微立体声扩展（BGM 可双声道）。
- **必须模拟 NES 限制以获得年代感**：
  - 音量按 4-bit 台阶量化（16 级）。
  - 音高按 NES 的 11-bit 定时器量化（会有轻微走音，这是味道）。
  - 同时最多 2 个方波 + 1 三角波（贝斯）+ 1 噪声（打击乐）声部。
  - 包络用简单的 攻击/衰减/持续/释放 台阶，不要平滑指数曲线。
  - 音符之间加入 1 帧（约 16ms）的静音间隙，模拟 NES 音序器。
- 输出格式：**同时输出 `.mp3`（128kbps）与 `.ogg`（q4）**，两份同名。用 ffmpeg 转码（wav 中间文件生成到 `tools/_tmp_audio/`，不要提交）。
- 输出目录：`assets/audio/sfx/` 与 `assets/audio/bgm/`。
- 生成脚本：`tools/gen_audio.py`（可重复运行，一次生成全部）。
- 最后必须输出一份 `assets/audio/manifest.json`：
  ```json
  { "sfx": [{"key":"ui_move","file":"sfx/ui_move","duration":0.08,"volume":0.6}], 
    "bgm": [{"key":"bgm_room","file":"bgm/bgm_room","duration":32.0,"loop":true,"volume":0.45}] }
  ```
  `file` 字段**不带扩展名**（代码会自动补 .mp3/.ogg）。

## 自查（必做）
生成后用 `ffprobe` 逐个校验：文件存在、时长符合、非静音（用 `ffmpeg -af volumedetect` 检查 mean_volume 不为 -inf 且峰值不削顶）。把校验结果打印出来。BGM 要检查首尾能否无缝循环（首尾 0.05s 的波形应接近，必要时做尾部淡接到头部）。

## 二、背景音乐（`assets/audio/bgm/`）

要求：全部为**可无缝循环**的 chiptune，2 方波（主旋律+和声）+ 1 三角波（贝斯）+ 噪声（打击乐）。
**旋律必须自己写，不得抄袭任何现有作品的旋律。** 多用**中国五声音阶（宫商角徵羽 = C D E G A）**以贴合"中国式"气质。

| key | 时长 | BPM | 情绪与写法 |
|---|---|---|---|
| `bgm_title` | 30s | 96 | 标题曲。怀旧、有一点感伤又带期待。五声音阶主题，主旋律用 50% 占空比方波（音色圆润），贝斯走缓慢的根音，打击乐只在每小节第一拍轻点。中段升高八度重复一次主题。 |
