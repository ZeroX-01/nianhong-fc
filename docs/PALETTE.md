# 《那年的红白机》统一美术规范（所有资源生产者必读）

## 0. 项目定位
1990 年代中国家庭客厅，孩子偷玩小旋风游戏机（红白机兼容机）的怀旧像素游戏。
情绪关键词：老旧、温暖、发黄、傍晚斜阳、CRT 荧光、水泥墙、木家具、蕾丝罩布。
**不要**赛博朋克、不要霓虹紫蓝渐变、不要现代扁平插画感。

## 1. 分辨率与坐标
- 游戏基准逻辑分辨率：**480 × 270**（16:9），整数倍放大到屏幕。
- 内嵌小游戏画面区（模拟 4:3 CRT）：**360 × 270**，居中，左右各 60px 为电视木质边框。
- 所有 sprite 必须是 **1:1 像素**，禁止抗锯齿、禁止半透明羽化边缘、禁止渐变柔化。
  - PIL 绘制时一律用 `Image.new("RGBA", ...)` + 逐像素/矩形填充，禁止 `ImageDraw.ellipse` 的默认反锯齿之外还要注意：如需圆形请自己按像素判定，或绘制后做 alpha 二值化（alpha >= 128 → 255，否则 0）。
  - 缩放一律 `Image.NEAREST`。

## 3. 材质画法约定
- **木家具**：WOOD2 描边，WOOD4 主体，WOOD5/WOOD6 顶面受光，WOOD1 阴影。木纹用 1px 断续横线（WOOD3）。
- **金属（主机卡槽、螺丝、AV 线插头）**：GREY3 描边，GREY5 主体，GREY7 高光 1px，INK 阴影。
- **塑料（主机壳、手柄）**：主体色 + 上缘 1px 亮色高光 + 下缘 1px 暗色。
- **玻璃（电视屏、鱼缸）**：主体暗色 + 左上到右下的 45° 斜向 2px 白色高光条（GREY8，可用 dither 减淡）。
- **描边**：所有独立物件必须有 1px 深色描边（用该物件主色系的最暗色，不要一律用纯黑）。
- **织物（蕾丝罩布、沙发、被面）**：用 dither 做花纹，蕾丝边缘做锯齿状小三角。

## 4. 输出要求
- 格式：PNG，RGBA，透明背景（除明确要求整幅背景图的）。
- 命名：全小写，下划线分隔，严格按各 SPEC 给出的文件名，**不得改名、不得改尺寸**。
- 多帧动画：横向排列的 sprite sheet，每帧等宽，帧数严格按 SPEC。
- 生成脚本放在 `tools/`，必须可重复运行（`python3 tools/gen_xxx.py`）。
- 生产完毕后必须自查：用 `read` 工具以 `view_type=image` 查看每张关键图（可先拼成放大 4 倍的 contact sheet），确认造型可辨识、无锯齿毛边、无调色板外颜色，不满意就重画。
