# 那年的红白机

2026 年 7 月 3 日夜里 23:47，你在公司 18 层干完最后一版发布，下楼、打车、坐进后座。手机刷到一个「二十年前的游戏机」的视频，评论区最高赞写着「我现在赚的钱能买十台，可我想的还是那一台」。你眨了三次眼，第三下没有睁开。

醒过来是 2004 年 7 月 15 日，暑假第一天。客厅电视柜上那台小旋风不是你家的——你爸单位同事家的孩子上初中了，机器先搁在你家，说好开学前还回去，这句话你妈说了三遍。你有 48 天，和一台标价 45 块的二手主机。

于是你在集市上淘二手卡带，回家插上去满屏花花绿绿，拔下来，对着金手指哈两口气，在裤子上蹭一下，再插回去——「叮——」画面出来了。

浏览器直接打开就能玩。没有构建步骤，没有账号，存档在 localStorage 里。
**在线试玩：见仓库首页的 About 链接**（手机也能玩，会自动出虚拟十字键）

> 版本现状：这个仓库就是 v1 的全部源码，没有构建步骤，克隆下来起个静态服务器就能玩。

## 怎么跑起来

任意静态服务器指向项目根目录即可（`file://` 下浏览器会拦音频与部分资源，请务必用 http）：

```bash
cd nianhong-fc
python3 -m http.server 8100
# 打开 http://localhost:8100/index.html
```

首屏会有一句「点击开机」——这是浏览器的音频解锁要求，点一下才有声音。

不熟命令行的话看 [`如何在自己电脑上运行.md`](如何在自己电脑上运行.md)，那份是一步一步写的。

## 序章：2026 年那个晚上

开新档的第一件事不是暑假，是 12 镜（S-01 ~ S-12）的加班夜：公司 18 层只剩一排灯 → 发布完成的提示框 → 电梯里叫车「预计等待 14 分钟」 → 楼下雨里等车 → 出租车后座 → 收音机里蹦出几个方方正正的电子音 → 刷到那条评论 → 三次眨眼 → 蝉声和铁窗晒了一整天的味道 → 有人在楼下喊你的小名。屏幕顶上一直挂着日期条，从 `2026 年 7 月 3 日` 到第 11 镜换成 `2004 年 7 月 15 日`。

**节奏是「读完再点」，不自动翻页。** 一行字打完就停下来等你，右下角闪一个 `▼`：

| 这时候 | 按 A（或点画面 / START） |
| --- | --- |
| 一行还在打字 | 一次打完这行 |
| 一行已经打完（`▼` 在闪） | 走下一行；本镜最后一行则进下一镜 |
| 最后一镜 | 进 2004 年的客厅 |

早先是旁白自己往下走、A 只管加速，实测 12 镜像放幻灯片一晃就过去了，玩家根本没看清自己看了什么，所以改成了现在这样。

**能跳，但有两镜不给跳。** 随时按 B 或点右上角「跳过」就走，跳过不是什么都不给——会补三行摘要，否则你不知道自己为什么在 2004 年。例外是 S-10（三次眨眼）和 S-11（色温从冷蓝迁到暖黄）这两镜，一共 6 秒，这 6 秒是「2026 变成 2004」的全部交代，按 B 只会得到一句「这一段跳不过去，6 秒就好。」

**看过之后随时能重看。** 回忆册第一页常驻一条「那个晚上」，选中按 A（或再点一次）就从头放一遍，重看不动存档、看完回到册子。

老存档（VER<3）读进来一律记成「序章已看过」——老玩家的夏天早就开始了，半路给他插四分钟加班夜等于打断进度；想看就去回忆册第一条。

## 操作

| 动作 | 键盘 | 手柄 | 手机 |
| --- | --- | --- | --- |
| 移动 / 选择 | ↑↓←→（小游戏里 `WASD` 也是方向） | 十字键 / 左摇杆 | 屏幕左侧虚拟十字键 |
| A（确认 / 跳 / 开火 / 哈气按住） | `X` `K` `空格`（小游戏外还有 `A`） | A / ○ | 右侧 A 键 |
| B（取消 / 副武器 / 跳过序章） | `Z` `J` `B` | B / × | 右侧 B 键 |
| START（暂停 / 修卡台里「插回去开电视」/ 妈妈预警时开始收拾） | `Enter` | START | 屏幕右上 |
| SELECT（客厅里开系统菜单；个别小游戏的秘技键） | `Shift` | SELECT | — |
| 2P（发小家两人同屏） | `WASD` + `G` `H` | 第二个手柄 | — |

小游戏里 `A` 是「往左走」而不是确认：一坐下就按 `WASD` 想开坦克的人太多了，移动比确认要紧。菜单、客厅、修卡台这些地方 `A` 照旧是确认，此时提示条会自动改口只写 `X`。每张卡真正能动的那一刻，电视画面里会自己弹一张「怎么玩」（3.5 秒自己收，按任意键立刻收），暂停菜单里也能随时再叫出来。

鼠标 / 触屏可以直接点场景里的东西。客厅一共 13 个可点物件：电视机、小旋风主机、装卡带的鞋盒、沙发、小方桌、门、窗户、灯、金鱼缸、挂历、暖水瓶、奖状、挂钟。修卡台上还能用手指在卡带上左右划——那就是在桌沿上蹭金手指。

## 玩什么

- **一条正经目标：买下自己那台。** 客厅那台是借的，开学前必须还（存档里 `story.lent` / `dueDay = 48`）。集市上有一台二手小旋风主机，标价 45 块、每天在 41–49 之间浮动。每天五毛零花钱，卖废品、退酒瓶、卖旧课本、帮人搬货各有零头，全部记进账本；心愿单和集市提示条常驻显示「还差多少」。48 天不是倒计时压力，是一条能每天推一点的进度条。
- **修卡是这游戏的心脏**。每张卡带有「脏」和「磨损」两个值，主机卡槽还有自己的灰。开机失败会抽一种故障，故障现象直接告诉你该干什么：
  | 现象 | 该做的事 |
  | --- | --- |
  | 雪花没信号 | 拔出来，插到底，「咔哒」一声 |
  | 花屏彩条 | 对着金手指哈两口气 |
  | 画面滚动偏色 | 拿卡带在桌沿上划两下 |
  | 抖动横条 | 在电视侧面拍一巴掌 |
  | 一层彩虹纹 | 对着卡槽吹灰 |
  刻意让「过犹不及」成立：哈久了金手指更湿，划多了是在磨掉这张卡的命（磨损永久不可逆，磨到底就彻底废了）。棉签能一次擦掉一大半脏污，但用一次少一支。哈气和划桌都有一段动作特写，看第二遍第三遍会自动变短。
- **妈妈机制**。开着电视玩的时候她随时可能回来，预警分三级：楼下自行车铃 → 楼道脚步声加心跳 → 钥匙插锁。门开那一刻她只硬查两件事：电视关了没、卡带拔了没。惩罚按累计次数升级——罚写两页大字 → 手柄被没收放到大衣柜顶上 → 直接把卡带没收走。桌上摊开一本作业本能把惩罚降一档，但救不了「电视还开着」。
- **抢救那三下**（听见动静之后的手忙脚乱）。预警一响，按 `START` 开始收拾，要做三件事：**关电视 → 拔卡带 → 塞沙发缝**。每件事屏幕上都有一根判定条，一个光标来回扫，看着条子按 `A`：
  | 判定 | 结果 |
  | --- | --- |
  | 正好 | 白赚，不耽误时间 |
  | 勉强 | 这一步过了，但妈妈的脚步往前挪了约 0.45 秒 |
  | 手滑了 | 往前挪约 1.1 秒，而且这一步得重来 |
  越急判定区越宽，可是光标也越快——所以不是「越晚越难」，是「越晚越像真的手抖」。听到钥匙插锁（第三级）会自动进入收拾，不用你再按。这一段小游戏停着，妈妈的秒表照跑，暂停菜单和右上角的「离开」都不给用：你只能收拾，或者被抓。三下全对是「干净收场」，还能换一点她的信任；收到一半门就开了，就按当时的真实状态清算。

- **集市**。二手卡带摊要还价（一口价的直接买），有真卡有假卡，有 100 万合 1 这种拼盘，也有《西游记（未完成版）》这种插上去就崩的。零碎货：清洁棉签、像样点的 AV 线（降低开机失败率）、山寨 2P 手柄、《电子游戏时代》、老冰棍、二手小台扇，以及那台 45 块的二手主机。
- **发小家**。他有两个手柄，可以两人同屏坦克；也可以跟他借卡带回家玩（他不一定肯借，借来的七天后要还）。
- **写作业**。按笔顺输入方向键写字，一个字 +12 进度，写够了妈妈才让你玩。
- **48 天的暑假**（7/15 – 8/31），一天五个时段（上午 / 中午 / 下午 / 傍晚 / 晚上）、4 点精力，精力用完就睡觉。随机事件（下暴雨拔插头、停电、太热主机烫手、表哥来串门、期末成绩单发了零花钱……），最后一天有结局与回忆册。结局按「买到没买到」×「和你妈的关系好不好」分四种（`own_warm` / `own_cold` / `lost_warm` / `lost_cold`），都不命中时走一个兜底。
- **心情不是资源条**。它是 0–100 的一个数，五档各有一个词（从「一点劲都没有」到「美得很」），不消耗、不阻塞任何操作，只做叙事晴雨表和结局判定。
- **麦克风彩蛋**：设置里打开「用麦克风哈气」，就真的可以对着屏幕吹气来修卡（要浏览器权限，要不到会老实退回长按）。

### 名字全是自己编的

这是一部独立作品，画面上出现的每一个牌子和每一张卡带名都是虚构的：主机叫**小旋风**，开机画面写 `1994 XUANFENG`，杂志叫《电子游戏时代》，卡带是《魂斗萝》《铁甲坦克1990》《超级马里蘑》《拳霸98加强变态版》。玩法上的手感是在致敬那个年代的几张卡，名字和美术都不照搬。`tools/check_words.py` 会在上线前扫一遍上屏文案，商标词、真实作品名、内部信息一个都不许留。

### 卡带（都是致敬式的化名）

魂斗萝 / 铁甲坦克1990 / 超级马里蘑 / 拳霸98加强变态版 / 100万合1 / 赤血要塞·汉化版 / 方块大陆（无敌版）/ 足球小子 / 冒险蛋 / 雪人哥俩 / 影子传书 / 西游记（未完成版）

其中**四张是真能玩的完整小游戏**（魂斗萝、铁甲坦克、超级马里蘑、拳霸），其余按「插上去会发生什么」分别做成合卡菜单、乱码汉化、空卡、崩溃卡等演出。

## 开发与测试

### 起服务器

```bash
cd nianhong-fc
python3 -m http.server 8100
```

**注意**：多数测试脚本的端口是写死在源码里的（`8100`，坦克 `8102`、马里蘑 `8103`、拳霸 `8104`），命令行传参不生效；只有 `prologue_test` / `prologue_shots` / `bugfix_title_room_test` / `move_input_test` / `repair_anim_test`（默认 `8110`）能接端口或完整 URL。跑之前先确认端口是你自己的，否则会测到别的站点、得到一整片莫名其妙的失败。详见 [`docs/TESTING.md`](docs/TESTING.md)。

### 跑回归

全部是 Playwright 无头浏览器跑真实操作（点鼠标、按键盘、模拟触屏），不直接调场景方法。语法先过一遍，再按需要跑：

```bash
node --check src/core/*.js src/data/*.js src/systems/*.js src/scenes/*.js src/games/*.js src/anim/*.js src/main.js

python3 tools/check_font.py                   # 字库体检：源码里写了的字能不能上屏（缺字是静默失败）
python3 tools/check_words.py                  # 文字规避：上屏文案里的商标词 / 真实作品名 / 内部信息

node tools/gametest/gamekeys_test.js          # 电视里的按键指引：时机、内容、不压 HUD    121 过
PORT=8100 node tools/gametest/story_core_test.js  # 借来的机器/二手主机/账本/心情/结局      80 过
node tools/gametest/keys_ui_test.js           # 键位、可点返回、详情面板排版、缺字         73 过
node tools/gametest/prologue_test.js 8100     # 序章 12 镜：结构/节奏/跳过/老档/重看/门禁  63 过
node tools/gametest/move_input_test.js        # 小游戏 WASD、开场提示、触屏十字键命中      45 过
node tools/gametest/systems_test.js           # 系统单测：时间/经济/修卡/妈妈/存档/资源     44 过
node tools/gametest/rescue_test.js            # 抢救那三下：判定档位、罚时、干净收场、被堵门 37 过
node tools/gametest/bugfix_title_room_test.js 8100  # 标题死屏 + 客厅点击框重叠回归        37 过
node tools/gametest/flow2_test.js             # 集市买卡 / 借卡 / 被妈抓 / 抢救三下 / 结局  31 过
node tools/gametest/repair_anim_test.js 8100  # 哈气/划桌动作特写（**必须单独跑**）        30 过
node tools/gametest/flow3_test.js             # 零碎货与还价 / 两人同屏 / 写作业 / 手机触屏 19 过
node tools/gametest/settings_test.js          # 设置面板：音量实时生效 / 显像管 / 麦克风降级 16 过
node tools/gametest/flow_test.js              # 主线：鞋盒→插卡→开机花屏→对症修卡→进游戏   ✓
node tools/gametest/play_integration.js       # 卡带全部能进 Play 且不报错                 8/8
```

`flow_test.js` 会按当次随机抽到的故障类型选择对症手法（雪花就插到底、抖动就拍一巴掌……），所以每次跑的路径都不一样；`flow3_test.js` 里 `DEBUG_UI=1` 可以打开 UI 输入追踪。截图落在 `tools/gametest/<用例名>/`。

`repair_anim_test.js` 的哈气力度按真实按住时长算，和别的套件并行时机器一慢就会「哈过头」导致假失败——单独跑。

改完代码不确定该跑哪几个，查 [`docs/TESTING.md`](docs/TESTING.md) 的回归矩阵。

### 打包与部署

```bash
bash tools/build_dist.sh                              # 打包到 dist/（246 个文件 / 9.3MB，音频只留 mp3）
node tools/gametest/deployed_smoke.js <线上地址>       # 线上冒烟：资源 404、音频丢没丢、能不能真的进游戏
```

`dist/` 是产物目录，不入库；线上就是这份包。打包时会把 `ogg` 删掉、并改掉加载器里的音频候选格式（为了压住部署平台的文件数上限），所以只有 `deployed_smoke` 会专门盯音频数量。

## 已知限制

- 麦克风哈气默认关闭，需要在设置里手动打开并授权；无头环境 / 拒绝授权时自动退回长按 A。
- 手柄依赖浏览器 Gamepad API，需要先按一下键才会被浏览器识别。
- 音频与美术都是程序生成的近似 NES 风味，不是原版素材。
- `test-game.html` 是单个小游戏的调试页，没有初始化完整的 `window.SB`，仅供开发时看画面。
- 存档在 localStorage，换浏览器 / 清缓存会丢；设置里「清空存档」可以重开这个夏天。
- 小游戏开机标题卡上写的 `1994 XUANFENG` 是**机器年份 / 致敬信息**，和叙事年份（2026 / 2004）无关，不要顺手改。
- 结局停在 2004 年 8 月 31 日，末尾两句把镜头轻轻拉回现在，但没有一个「醒来回到 2026」的正式段落。
